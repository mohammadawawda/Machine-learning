# Linear regression

* `linear_regression.py` least squares linear regression with numpy
* `polynomial_fitting.py` polynomial fitting on top of the linear regression
* `house_price_prediction.py` cleans the house prices data, checks how every feature relates to the price, and shows how the test loss changes as the train set grows
* `city_temperature_prediction.py` looks at daily temperatures in a few countries, fits a polynomial to the temperature by day of the year in Israel, and then tests it on the other countries
* `answers.pdf` the math and all the plots

## How to run

The scripts read `house_prices.csv` and `city_temperature.csv`, which are not included.

```
python house_price_prediction.py
python city_temperature_prediction.py
```
