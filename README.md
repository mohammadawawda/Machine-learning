# Machine Learning

Machine learning algorithms, mostly written from scratch with numpy, and experiments on real data.

* [linear_regression](linear_regression) linear regression and polynomial fitting from scratch, used to predict house prices and city temperatures.
* [boosting_and_cross_validation](boosting_and_cross_validation) AdaBoost with decision stumps, and k fold cross validation to choose lambda for ridge and lasso.
* [gradient_descent](gradient_descent) gradient descent on L1 and L2, and regularized logistic regression on heart disease data.

To install the packages run `pip install -r requirements.txt`
